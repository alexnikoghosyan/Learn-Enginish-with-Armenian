# Առաջադրանք Claude Code-ի համար. Ֆիզիկա 7 — ուղու նոր կլորակներ

Կարդա նախագծի `CLAUDE.md`-ը և հետևիր դրա կանոններին։ Հետո իրականացրու ստորև նկարագրածը `/physics` ուղու վրա։

## 0. Աղբյուրներ
- Այս թղթապանակը (`design/physics-path-nodes/`) պարունակում է վերջնական դիզայնի 6 ֆայլ, մեկ ֆայլ ամեն գլխի համար.
  `Ch1-Methods-Start.dc.html`, `Ch2-Matter-Start.dc.html`, `Ch3-Motion-Start.dc.html`, `Ch4-Interaction-Start.dc.html`, `Ch5-Work-Start.dc.html`, `Ch6-Gauge-Start.dc.html`։
- Դրանք Claude Design կտավի ֆայլեր են։ Դրանցից վերցրու **SVG նկարները, CSS-ը (keyframes, կանոններ) և JS տրամաբանությունը**։ Կայքում այդ ձևաչափը չի աշխատում, ուստի այն պետք է փոխադրել կայքի vanilla JS-ի (`innerHTML`) ոճին.
  - `<x-dc>`, `<helmet>`, `support.js`, `DCLogic` → չկան կայքում։ `<helmet><style>`-ի CSS-ը տեղափոխիր `dist/physics.css` (կամ առանձին `dist/physics-nodes.css`, որը միացվում է `index.html`-ում)։
  - `{{c0}}`, `{{e0}}`, `{{o0}}` և այլն → `renderVals()`-ի հաշվարկած արժեքներն են (դասեր, `aria-expanded`, պատուհանի բաց լինելը)։ Կայքում դրանք հաշվիր JS-ով և դիր class/attribute-ների մեջ։
  - `<sc-if value="{{o0}}">…</sc-if>` → պայմանով նկարվող HTML (պատուհանը կամ դասի էկրանը)։
  - `onClick="{{k0}}"`, `onMouseEnter="{{m0}}"`, `onMouseLeave="{{l0}}"`, `onClick="{{g0}}"` → իրադարձությունների մշակիչներ (event delegation կամ `addEventListener`)։
  - Դիզայնի ֆայլերում ուղու կոորդինատները (`NODES`) և դասերի անունները օրինակ են։ Ուղու դասավորությունը թող լինի կայքում եղածը, իսկ անունները վերցրու `PHYSICS_COURSE`-ից (`dist/physics-course.js`)։
- **Դասի էկրանը** (`.lesson` ծածկույթը՝ «Այստեղ կբացվի դասի առաջին քայլը») միայն օրինակ է։ Կայքում դրա փոխարեն պետք է բացվի իրական դասը (տե՛ս §4)։

## 1. Կլորակն ըստ գլխի
Գլխի գույնը կապիր `PHYSICS_COURSE.chapters[i]`-ի հետ։ Կլորակը ամբողջ գլխում նույնն է, փոխվում է միայն վիճակը։

| Գլուխ | Կլորակ | Հիմնական / մուգ / բաց գույն | Ֆայլ |
|---|---|---|---|
| I | Խոշորացույց | #58CC02 / #58A700 / #89E219 | Ch1-Methods-Start |
| II | Ատոմ (էլեկտրոնները 120°-ով, միջուկը r=29) | #CE82FF / #A568CC / #E3B5FF | Ch2-Matter-Start |
| III | Անիվ (կետագծային հետագիծ դասերի միջև) | #1CB0F6 / #1899D6 / #84D8FF | Ch3-Motion-Start |
| IV | Զսպանակից կախված բեռ (mg/F սլաքներով) | #FF9600 / #CC7800 / #FFC266 | Ch4-Interaction-Start |
| V | Ատամնանիվ | #FF4B4B / #EA2B2B / #FF9B9B | Ch5-Work-Start |
| VI | Մանոմետր | #00C2D1 / #009FAB / #7FE6EE | Ch6-Gauge-Start |

Գլխի պաստառի (`ԳԼՈՒԽ …`) ֆոնը հիմնական գույնի մգացված տարբերակն է, որի դեպքում սպիտակ տեքստի կոնտրաստը ≥ 4.5 է (տե՛ս ֆայլերում)։

## 2. Վիճակներ
- **ավարտված**՝ գլխի գույն + նշիչ (I–V-ում նշիչը կլորակի մեջ է, VI-ում՝ կանաչ նշիչ անկյունում)։
- **ընթացիկ**՝ գլխի մշտական թեթև շարժում (ուղեծրերի դանդաղ պտույտ, բեռի տատանում, սլաքի տատանում և այլն) + վերևում ցատկոտող «ՍԿՍԵԼ» պիտակ (IV-ում պիտակը կողքին է)։
- **փակ**՝ մոխրագույն + կողպեք։
- Ընթացիկ դասի շուրջը պուլսացող/մեծացող օղակ **չպետք է լինի**։ Եթե կայքում կա, հանիր։
- Կլորակները կոճակի պես **«ներս չեն մտնում»** սեղմելիս (`:active`-ով translateY չանել)։ Ներս մտնում է միայն պատուհանի իսկական կոճակը։

## 3. Փոխազդեցություն
Ֆայլերում ամեն շարժվող մաս ունի շերտերի կարգ՝ `c-` (մեծ անիմացիա, «ՍԿՍԵԼ») > `p-` (սեղմելու փոքր անիմացիա) > `o-rot` (պտույտի պահված անկյուն) > `h-` (մկնիկը վրան) > նկար։ Պահպանիր այս կառուցվածքը, որ անիմացիաները իրար չխանգարեն։

1. **Մկնիկը վրան.** `mouseenter`/`mouseleave`-ով դիր/հանիր `hov` դասը (ոչ թե CSS `:hover`)։ IV-ում դասը դրվում է `.grp`-ի վրա (զսպանակ + բեռ), մյուսներում՝ կլորակի կոճակի վրա։ Անիմացիաներն ու կանոնները՝ ֆայլերից (`.chN .node.hov:not(.locked) …`)։ Միայն մկնիկով սարքերում (`matchMedia('(hover: hover)')`)։
2. **Մկնիկը հանելիս ոչինչ կտրուկ չի վերադառնում.** տե՛ս ֆայլերի `settle(root)` մեթոդը և նույնը արա կայքում.
   - `hov`-ը հանելուց առաջ վերցրու ամեն անիմացվող տարրի ընթացիկ `transform`/`opacity`-ն (`getAnimations()`), հանիր `hov`-ը և Web Animations API-ով 380 մվ-ում (`cubic-bezier(.2,.7,.3,1)`) սահուն տար տեղը։
   - Պտտվողները (`.h-orb`, `.h-sp`, `.h-gb`) **ետ չեն գնում**. ընթացիկ անկյունը կուտակիր ծնող `.o-rot`-ի վրա (`data-rot` + `style.transform`), և ավելացրու իներցիա․ 750 մվ, `Δ = v·T/3`, `cubic-bezier(.2,.6,.4,1)`։ Ընթացիկ դասը հետո շարունակում է իր դանդաղ պտույտը, ավարտվածը կանգ է առնում։
3. **Կլորակը սեղմելիս** խաղում է փոքր անիմացիա (`tapA`/`tapB` դասերը հերթափոխով, որ ամեն սեղմում նորից սկսի), և կլորակի տակ բացվում է **դասի պատուհանը**.
   - ավարտված՝ դասի անունը, «Ավարտված է։ Կարող ես կրկնել։», կոճակ «ԿՐԿՆԵԼ»
   - ընթացիկ՝ «Հաջորդ դասը քեզ է սպասում։», կոճակ «ՍԿՍԵԼ»
   - փակ՝ մոխրագույն պատուհան, «Ավարտիր նախորդ դասերը, որ այս դասը բացվի։», անգործուն «ՓԱԿ Է», և կլորակը թափահարվում է։
   - Միաժամանակ բաց է միայն մեկ պատուհան։ Նույն կլորակը նորից սեղմելիս փակվում է։ Ավելացրու նաև `Escape`-ով և պատուհանից դուրս սեղմելով փակելը։
   - **IV գլխում** պատուհանը բացվում է մյուսներից 28px ավելի ներքև, որ իջնող բեռը չծածկվի։ VI-ում՝ 6px ավելի ներքև։
4. **Պատուհանը բաց լինելու ընթացքում** կլորակը պահում է `hov` վիճակը (բոլոր 6 գլուխներում)։ Փակվելիս կամ ուրիշը բացելիս կանչվում է `settle`-ը։
5. **«ՍԿՍԵԼ»/«ԿՐԿՆԵԼ»** (ֆայլերում՝ `start(i)`).
   - Պատուհանը անմիջապես փակվում է, կլորակի վրա դրվում է `clickA`/`clickB`, և խաղում է մեծ անիմացիան։
   - Անիմացիայի ընթացքում այլ կլորակներ չեն արձագանքում (`busy`)։
   - Դասը բացվում է **անիմացիայի գագաթնակետին**, ոչ թե ավարտին։ Հանգստանալու մասը (օրինակ՝ մանոմետրի սլաքը կանաչ գոտի վերադառնալը) չպետք է երևա։ Ժամանակները «ՍԿՍԵԼ»-ից հետո.
     I 1150 մվ · II 900 մվ · III 620 մվ (անիվը հենց անհետանում է) · IV 850 մվ · V 1000 մվ · VI 850 մվ (սլաքը կարմիրում է, գոլորշին դուրս է գալիս)։
   - Այդ պահին անցիր դասին՝ կայքի եղած երթուղով (`/physics/lesson/<id>`, նույն ձևով, ինչպես հիմա է բացվում դասը)։ Անցումը թող լինի արագ (≈0,12 վ մարում)։
6. **`prefers-reduced-motion: reduce`.** Բոլոր անիմացիաներն անջատվում են (ֆայլերում կա `@media` բլոկը), և դասը բացվում է անմիջապես։

## 4. Մատչելիություն
- Կլորակը `<button type="button">` է՝ `aria-label` = «<դասի անուն> — ավարտված / ընթացիկ դաս / փակ», `aria-expanded`, `aria-controls` = պատուհանի id։ Փակ դասը `aria-disabled="true"` է (ոչ թե `disabled`, որ սեղմելիս թափահարվի)։
- SVG-ները `aria-hidden="true"`։ `:focus-visible` ուրվագիծը պահիր։ Կոնտրաստը ≥ 4.5։

## 5. Ստուգում
- `npm run build`, `npm test` (թարմացրու կամ ավելացրու թեստեր, եթե ուղու նկարումը թեստավորված է)։
- Playwright կամ բրաուզեր՝ 375px և 1280px.
  - ամեն գլխում մկնիկը վրան/հանել (առանց կտրուկ թռիչքների, պտտվողները ետ չեն գնում),
  - սեղմել → պատուհան → «ՍԿՍԵԼ» → դասը բացվում է նշված պահին,
  - փակ դաս (թափահարում + «ՓԱԿ Է»), `Escape`, դուրս սեղմել,
  - `prefers-reduced-motion`։
- Բջջայինում (`hover: none`) մկնիկի անիմացիաները չպետք է «կպչեն»։
