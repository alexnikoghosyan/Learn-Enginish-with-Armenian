# Flow prompts for the Physics 7 section (physics-src/images/<id>.png)

The images are generated by the user in Google Flow (not by Claude Code). After downloading, put them in
`physics-src/images/<id>.png`, run `python physics-media.py`, then `python physics-media.py --palette <id>` and compare the SVG
twin in `physics-src/compare/` (see PROGRESS.md → Next). Originals are git-ignored.

## Settings
- Image, 1:1, x1, Nano Banana Pro (use 2.1 if the limit is reached). At most 2-3 generations at a time.
- Make sure the send button is really pressed before waiting (the grid shifts when a generation starts).
- Download 1024x1024 (`=s0`). Downloading needs the user's permission.

## Style rule (same as the vocabulary object pictures)
Front-facing icon, centred, wide margins, white background. Two flat tones (a light half and a dark half), a darker "thickness"
layer shifted below the object, Duolingo palette (#1CB0F6 blue, #58CC02 green, #FFC800 yellow, #FF9600 orange, #CE82FF purple,
#FF4B4B red, #AFAFAF grey). No outline, no gloss, no gradient, no face, **no text or numbers**.

## Prompt template
```
A flat vector icon of {OBJECT}, front view, centred with wide margins, pure white background.
Two flat tones only (a lighter half and a darker half), plus a darker thickness layer offset below the object.
Duolingo-style palette ({COLORS}). No outline, no gloss, no gradient, no face, no text, no numbers.
```
