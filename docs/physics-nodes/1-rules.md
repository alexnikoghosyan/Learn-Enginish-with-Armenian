### B.4 Կլորակի SVG
`<svg aria-hidden="true" width="140" height="140" viewBox="0 0 140 140" style="overflow: visible">`

Երկու թույլատրելի ձև կա.
- **(a) ROUND (նախնական).** Մարմինը Ø72 շրջան է՝ `cx 70 cy 66 r 36`, main գույնով։ «Հաստությունը» նույն շրջանն է `cy 73`-ում, dark գույնով, և նկարվում է **առաջինը**։ Մոտիվը նկարվում է շրջանի վրա սպիտակով և light երանգով, զբաղեցնում է շրջանի մոտ 60–65%-ը (12-րդում ≤Ø50)։
- **(b) OBJECT.** Առարկան ինքն է կլորակը (օր.՝ 8-րդի թեք հարթությունը, հրթիռը, ճոճանակը)։ Այն նկարվում է գլխի գույներով և ունի նույն ձևի մուգ կրկնօրինակը `translate(0 7)`-ով։ Կլոր եզրեր ստանալու համար ձևը կարելի է նկարել նույն գույնի `stroke-width 10; stroke-linejoin:round` stroke-ով, որը եզրագիծ չի համարվում, որովհետև նույն գույնի է։

Ոճի կանոններ.
- Երկու հարթ երանգ + մուգ հաստություն (Duolingo)։
- **Արգելված է.** եզրագիծը (ուրիշ գույնի stroke ձևի շուրջ), gradient, gloss, փայլ, blur ստվեր, դեմքեր և կերպարներ, **տեքստ կամ թվեր նկարում**։ Թույլ են միայն ֆիզիկական նշանները՝ v, a, F, B, I, E, λ, q, +, −, N, S։
- Stroke-ը թույլ է միայն որպես **գիծ-օբյեկտ** (լար, թել, ճառագայթ, սլաքի ձող, բռնակ), ≥4px հաստությամբ։ Ձող կամ թել ≥3.5px է։
- Սպիտակ էջի ֆոնի վրա (շրջանից դուրս) ընկած առարկաները **չեն կարող լինել սպիտակ**, այլ նկարվում են գլխի գույնով, այլապես անտեսանելի են։ Գոլորշին և ծուխը շրջանից դուրս `#E5E5E5` են։
- Ghost/strobe կրկնօրինակները հարթ tinted fill են (light գույն, opacity 0.35–0.6), **առանց եզրագծի**։
- Մոտիվի բոլոր կարևոր մասերը մնում են շրջանի ներսում կամ շատ մոտ (≤4px դուրս)։ Ջրափոսը, ալիքները և ճառագայթները հանգիստ վիճակում ու hover-ի ժամանակ չեն դուրս գալիս 140×140-ից։
- Եթե մոտիվի հիմնական գույնը սպիտակ է բաց ֆոնի վրա (օր.՝ սպիտակ թեյնիկ դեղին շրջանի վրա), մոտիվին տուր **իր սեփական մուգ «հաստությունը»** (նույն ուրվագիծը `translate(2 3)`-ով, dark-ից մուգ երանգով), որ ուրվագիծը կարդացվի։

### B.5 Վիճակներ
- **ԱՎԱՐՏՎԱԾ.** Round կլորակի վրա. `circle cx 102 cy 98 r 14 fill #58CC02` + `stroke #FFFFFF stroke-width 4` + սպիտակ check (`M95.3 98.4 L99.9 103 L109.1 93.4`, stroke 3.8, round)։ Object կլորակի վրա check-ը կարելի է նկարել ուղղակի առարկայի վրա (սպիտակ, stroke 7)։ Նշիչը START-ի ժամանակ մնում է տեղում, բացառությամբ այն դեպքի, երբ առարկան ինքն է դուրս թռչում, այդ դեպքում նշիչը դիր `c-` շերտի ներսում։

### B.6 Շերտերի (layer) կարգ — ՊԱՐՏԱԴԻՐ
Ամեն շարժվող մասի համար.
```
<g class="c-XXX">          ← START / click մեծ անիմացիա
  <g class="p-XXX">        ← tap (սեղմում) անիմացիա
    <g class="o-rot">      ← միայն պտտվողների համար (inertia)
      <g class="h-XXX">    ← hover անիմացիա
        <g class="idl|spin-slow|still"> ← idle (միայն ընթացիկի համար, այլապես «still»)
          … նկար …
```
- `transform-origin`-ը նշիր **բացահայտ, viewBox-ի px կոորդինատներով** (SVG-ի նախնական `transform-box:view-box`-ով), օր.՝ ճոճանակի կախման կետը `.ch3 .c-arm,.ch3 .p-arm,.ch3 .h-arm{transform-origin:70px 88px}`։ `transform-box:fill-box` օգտագործիր միայն մանր, ինքնուրույն տարրերի համար (կաթիլ, գոլորշու գունդ, կայծ)։
- Պտտվող մասը (անիվ, ատամնանիվ, փաթիլ, կոնվեկցիայի օղակ) hover-ի ժամանակ պտտվում է `.h-sp` (կամ `.h-gb`, `.h-orb`, `.h-cv`) class-ով, որի ուղիղ ծնողը `.o-rot` է։ Մկնիկը հանելիս այն ետ չի պտտվում, այլ իներցիայով դանդաղում է (Հավելված 2-ի `settle`)։
- Tap/click անիմացիաները պետք է վերագործարկվեն **ամեն սեղմման ժամանակ**, ուստի ամեն keyframe գրվում է երկու անունով. `name-ta` / `name-tb` (tap) և `name-a` / `name-b` (START)։ Կլորակը հերթով ստանում է `tapA`/`tapB` և `clickA`/`clickB` class-երը։ Կանոնի օրինակ.
  `.ch3 .done.tapA .p-arm,.ch3 .current.tapA .p-arm{animation:tick-ta .9s ease-in-out}` (և նույնը `tapB`-ով `tick-tb`-ի համար)։
- Hover-ը `hov` class-ն է. `.ch3 .node.hov:not(.locked) .h-arm{…}`։
- Hover-ի «պահվող» փոփոխությունները (թեքվել, մեծանալ, բարձրանալ) արա `transition`-ով (.25–.38s)։ Կրկնվող hover-ի շարժումները (դողալ, թրթռալ, ճոճվել) արա `animation`-ով։ Երկուսն էլ մկնիկը հանելիս սահուն վերադառնում են։

### B.7 @keyframes ինքնաստուգում — ՊԱՐՏԱԴԻՐ
- Ամեն keyframe բլոկ սկսվում է **ճիշտ `@keyframes`-ով**։ 8-րդ դասարանում իրական սխալ եղավ. ֆայլերում գրված էր `akeyframes`/`bkeyframes`, և հրթիռի, ճոճանակի ու թեք հարթության tap/START անիմացիաները ընդհանրապես չէին աշխատում։
- Ավարտելուց առաջ կազմիր երկու ցուցակ. (1) CSS-ում օգտագործված բոլոր `animation:` անունները, (2) բոլոր `@keyframes` անունները։ Ամեն (1) պետք է ունենա իր (2)-ը, և CSS-ի `{` ու `}` քանակները պետք է հավասար լինեն։ Ցուցակը կցիր զեկույցին (G)։

### B.8 JS տրամաբանություն
Ամբողջական կոդը Հավելված 2-ում է։ Վարքը.
- `state = { open: -1|i, t: [], g: [], h: [], busy: false, lesson: -1 }`
- `renderVals()` ամեն կլորակի համար տալիս է class string (`tapA|tapB` + `clickA|clickB` + `hov`), `open` flag-երը, `aria-expanded`-ը և handler-ները։
- `keep()` = true. քանի դեռ popup-ը բաց է, կլորակը պահում է hover-ը։
- `leave()` / `settle(root)`. մկնիկը հանելիս ոչինչ կտրուկ չի վերադառնում։ Ամեն անիմացված մաս 380 ms-ում `cubic-bezier(.2,.7,.3,1)`-ով գնում է իր ներկայիս դիրքից հանգստի դիրք (snapshot + `element.animate`)։ Պտտվողները իներցիայով դանդաղում են մոտ 750 ms (`data-rot`)։
- `toggle(i)` բացում/փակում է popup-ը կլորակի տակ։ Popup-ը 252px է, banner գույնով, պտտված քառակուսի սլաքով դեպի կլորակը։ Վերնագիրը 16px/800 է, տեքստը 14px/600, իսկ իսկական `<button class="cta">`-ը՝
  - ընթացիկ. «ՍԿՍԵԼ» + տեքստ ըստ E-ի,
  - ավարտված. «ԿՐԿՆԵԼ» + տեքստ ըստ E-ի,
  - փակ. disabled «ՓԱԿ Է», բաց մոխրագույն քարտ (`#F7F7F7`, border `#E5E5E5`), տեքստ «Ավարտիր նախորդ դասերը, որ այս դասը բացվի։» (`#6F6F6F`)։
- `start(i)`. popup-ը **անմիջապես փակվում է**, `busy = true`, խաղում է START անիմացիան, և `cut()` ms-ին (**անիմացիայի գագաթին**) բացվում է դասի էկրանը։ Անիմացիայի «հանգստանալու» մասը չի երևում։ Անիմացիայի ընթացքում մյուս կլորակները չեն արձագանքում։
- Դասի էկրանը ամբողջ artboard-ն է, `z-index 10`։ Վերևում X կոճակն է (44×44, `aria-label="Փակել դասը"`) և progress bar-ը (16px, գլխի main գույնով, 12%)։ Տակը գլխի պիտակն է (13px/800, banner գույնով), դասի վերնագիրը (24px/800) և placeholder տեքստը։ Fade-in-ը 120 ms է, բովանդակությունը սահում է 16px 300 ms-ում։
- Արգելված է. global `keydown`, script-ով կառուցված UI (`innerHTML`, `appendChild`)՝ Claude Design-ում։ Կայքում `innerHTML` թույլ է՝ ըստ կայքի կոդի։

### B.9 prefers-reduced-motion
- `@media (prefers-reduced-motion: reduce){ .chN *{animation:none !important;transition:none !important} }`
- `cut()`-ը վերադարձնում է 0, և դասը բացվում է անմիջապես։
- Թույլ է միայն opacity crossfade (≤150 ms), որը WCAG 2.3.3-ով «շարժում» չի համարվում։

### B.10 Մատչելիություն
- Կլորակը իսկական `<button type="button">` է, `aria-label="{դասի անուն} — ավարտված"` / `"— ընթացիկ դաս"` / `"— փակ"`, `aria-expanded`, `aria-controls="cardN"`։ SVG-ն `aria-hidden="true"` է։

- Տեքստի կոնտրաստը ≥4.5:1 է։ Ուրվագիծը սահմանող երանգը (սովորաբար հաստությունը) ֆոնի նկատմամբ ≥3:1 է **բոլոր վիճակներում**, hover-ում և dark ռեժիմում (WCAG 1.4.11)։ Եթե չի անցնում, մգացրու հաստությունը (օր.՝ դեղինի հաստությունը `#B08400`)։
- Վիճակը երբեք չի փոխանցվում միայն գույնով. նշիչը և կողպեքը ձևեր են։
- Թարթում 3 անգամից ավելի վայրկյանում չի լինում (WCAG 2.3.1)։

### B.11 Անվանումներ
- Ֆայլը `Ch{N}-{Topic}.dc.html` է, լատինատառ (առաջինը՝ `Main.dc.html`)։ Artboard-ի վերնագիրը «Գլուխ {N} · {կարճ վերնագիր} — {մոտիվ}» է։

## C. ՄՈՏԻՎ ՍՏԵՂԾԵԼՈՒ ԸՆԹԱՑԱԿԱՐԳ (ՑԱՆԿԱՑԱԾ ԹԵՄԱՅԻ ՀԱՄԱՐ)

**Քայլ 1 — Գլխի միջուկը։** Գրիր մեկ նախադասություն. «Այս գլխի կենտրոնական երևույթն է …»։ Վերցրու 4 դասերի ընդհանուր հայտարարը, ոչ թե միայն առաջինը։ Մոտիվը պետք է համապատասխանի **իրական գլխին PLAN.md-ում**։ 8-րդում մոտիվ եղավ գլխի համար, որը դասընթացում չկար, և այն հանվեց։

**Քայլ 2 — Կոնկրետ առարկա կամ դասական փորձ, որը ՑՈՒՅՑ Է ՏԱԼԻՍ երևույթը։** Կոնկրետը վերացականից լավ է, իսկ դասագրքի հայտնի փորձը՝ հատկապես (Գալիլեյի թեք հարթություն, Էրստեդի փորձ, Ֆարադեյի կծիկ, պրիզմա)։ Օրինակներ.
- Էլեկտրական հոսանք → լամպ + մարտկոց փակ շղթայում
- Մագնիսական դաշտ → պայտաձև մագնիս + կողմնացույցի սլաք
- Էլեկտրամագնիսական ինդուկցիա → մագնիս կծիկի մեջ + գալվանոմետրի սլաք
- Լույսի բեկում → պրիզմա + ճառագայթ
- Ոսպնյակներ → ուռուցիկ ոսպնյակ + 3 ճառագայթ կիզակետում
- Ձայն → բարձրախոսի թաղանթ + սեղմումների շերտեր
- Ձգողություն → մոլորակ + արբանյակ ուղեծրում (a սլաքը՝ դեպի կենտրոն)
- Իմպուլս → երկու սայլակի բախում
- Ջերմային մեքենա → մխոց + մխոցակ
- Ռադիոակտիվություն → α/β/γ և թուղթ/ալյումին/կապար
- Ֆոտոէֆեկտ → մետաղի թիթեղ + լույս + դուրս թռչող էլեկտրոն

**Քայլ 3 — 72px-ի ճանաչելիություն (ցածր դասի Android)։** ≤3–4 տարր, մեկ ամբողջական ուրվագիծ։ Գծերը ≥4px են, մանր դետալները ≥6px։ Մոտիվը պետք է կարդացվի 50% blur-ով և grayscale-ով։ Բարդությունը մշտապես վատացնում է որոնումը, իսկ կոնկրետությունը օգնում է միայն սկզբում (McDougall 2000)։

**Քայլ 4 — Եզակիություն։** Ուրվագիծն ու հիմնական շարժումը պետք է տարբերվեն B.12-ից և նույն դասարանի մյուս գլուխներից (պտույտ / թռիչք / ալիք / փուլային անցում / ճառագայթ / տատանում / բախում)։

**Քայլ 5 — Թյուրըմբռնումների ստուգում։** Անցիր D-ով։ Եթե մոտիվը կամ նրա անիմացիան կարող է ամրապնդել սխալ պատկերացում, փոխիր այն։

**Քայլ 6 — Չորս անիմացիա՝ նույն երևույթի չորս «ծավալով».**
- **IDLE** (միայն ընթացիկ դասի համար). երևույթի ամենափոքր, անվերջ դրսևորումը (կրակը թրթռում է, ճոճանակը թեթև ճոճվում է, կաթիլը սահում է)։
- **HOVER.** «Պատրաստվել» երևույթին կամ թեթև դրսևորում (կրակը մեծանում է, կափարիչը դողում է, գնդակը մի փոքր գլորվում է ու ետ գալիս, երևում են strobe կրկնօրինակները)։
- **TAP.** Մեկ իմպուլս (կափարիչը մեկ անգամ ցատկում է, մեկ «զնգոց», մեկ ճաք, գնդակի փոքր ցատկ)։ Popup-ը բացվում է tap-ի հետ միաժամանակ։
- **START.** Ամբողջ պատմությունը գագաթով, որից հետո `cut()`։ Պատմությունը պետք է ունենա 2–3 հստակ փուլ (օր.՝ թեյնիկ. կրակը բռնկվում է → ճնշումը աճում է, կափարիչը դողում է → գոլորշին բարձրացնում է կափարիչը = գագաթ)։

Ֆիզիկայի կանոնները անիմացիայում.
- Ազատ անկումը և գլորվելը արագանում են (ճանապարհը ∝ t², ease-in), իսկ վեր նետվածը դանդաղում է մինչև գագաթ։
- Ճոճանակի պարբերությունը կախված չէ լայնույթից, ուստի լայնույթը մեծանալիս պարբերությունը չի փոխվում։
- Ալիքի մասնիկները տատանվում են տեղում, շարժվում է միայն նախշը։ Անկման անկյունը հավասար է անդրադարձման անկյանը։
- Փուլային անցման ժամանակ կա կարճ դադար (ջերմաստիճանը հաստատուն է)։
- Գլորվող գնդակի պտույտը համապատասխանում է անցած ճանապարհին (անկյուն = s / r)։

**Քայլ 7 — Ժամանակներ** (դասարանային ճշգրտումները E-ում).
- Micro-feedback (hover, tap, popup). 150–420 ms։ Popup-ը բացվում է 200–250 ms-ում։
- **START. 800–1200 ms, իսկ `cut`-ը 600–1000 ms է՝ գագաթին։** Սա START-ի համար NN/g-ի «100–500 ms» կանոնից գիտակցված բացառություն է. START-ը պատմողական անցում է, որը խաղում է **մեկ անգամ** ամեն դասի բացման ժամանակ, ոչ թե հաճախակի feedback (Material 3-ում extra-long տիրույթը հասնում է 1000 ms-ի)։ 8-րդի թեստում 300–700 ms-ը **չէր կարդացվում**. սառույցը «հալվում էր» 0.3 վ-ում և անտեսանելի էր։
- Easing. մուտքը decelerate է (`cubic-bezier(.2,.6,.4,1)` կամ `(.2,0,0,1)`), ելքը accelerate (`cubic-bezier(.6,0,.8,.4)`)։ Overshoot-ը թույլ է միայն եթե դասարանը թույլ է տալիս (E)։
- Mouse leave-ի settle-ը 380 ms է, պտտվողների իներցիան՝ մոտ 750 ms։

**Քայլ 8 — Գագաթը և cut()։** Գագաթը ֆիզիկական կուլմինացիան է. օբյեկտը դուրս է գալիս կադրից, հասնում է ամենաբարձր կետին, ալիքը հասնում է եզրին, փուլային անցումն ավարտվում է, սլաքը առավելագույն շեղման մեջ է։ `cut` = գագաթի ժամանակը START-ի սկզբից։ Ստուգիր, որ գագաթը **երևում է** մինչև cut-ը (օր.՝ գոլորշին արդեն բարձրացել է)։

**Քայլ 9 — Խուսափիր.** confetti, աստղիկներ, ոչ ֆիզիկական կայծեր և «փայլեր», կերպարներ, թեմայից դուրս էֆեկտներ, >4 տարր, մեկից ավելի idle շարժում մեկ կլորակում, թարթում։ Ձայները նախնականում անջատված են։ Seductive details-ը (գեղեցիկ, բայց անկապ դետալներ) վնասում է ուսմանը (g ≈ −0.16…−0.33)։

**Քայլ 10 — Ստուգում։** Անցիր F-ով։ Եթե կարող ես, բացիր ֆայլը բրաուզերում (օր.՝ Playwright/headless Chrome), վերցրու START-ի կադրերը 0, 150, 300… ms-ին և նայիր իրական չափով ու 3× մեծացված։ 8-րդում հենց այդպես գտնվեցին «կողպեքի տեսքով» թեյնիկը և շրջանից դուրս եկող ջրափոսը։

## D. ԹՅՈՒՐԸՄԲՌՆՈՒՄՆԵՐԻ ՍՏՈՒԳԱՑՈՒՑԱԿ (✗ մի՛ նկարիր → ✓ նկարիր)

**Մեխանիկա**
- ✗ Հրթիռը «հրում է օդը կամ գետինը», ծխի ամպ, որին հենվում է → ✓ գազի նեղ շիթ հետ, հրթիռը առաջ։ Աշխատում է նաև վակուումում։
- ✗ Հավասարաչափ շրջանային շարժումը «առանց արագացման» է → ✓ a սլաքը դեպի կենտրոն է։ «Կենտրոնախույս» սլաք դեպի դուրս չկա։
- ✗ Թելը կտրելիս մարմինը թռչում է շառավղով → ✓ շոշափողով։
- ✗ Զանգվածը փոխում է ճոճանակի պարբերությունը → ✓ չի փոխում։ «Ծանր մեծ գունդ» մի շեշտիր։
- ✗ Ծանրը ավելի արագ է ընկնում (վակուումում) → ✓ միաժամանակ են ընկնում։
- ✗ Strobe կրկնօրինակների պատահական հեռավորություններ → ✓ հավասարաչափ արագացման դեպքում 1:3:5:7։
- ✗ «Տիեզերքում ձգողություն չկա» → ✓ անկշռությունը ազատ անկում է։ Սլաքը, եթե կա, դեպի մոլորակի կենտրոն է։
- ✗ Ուժը պետք է շարժումը պահպանելու համար → ✓ ուժը փոխում է արագությունը (Նյուտոնի I և II)։

**Տատանումներ, ալիքներ, ձայն**
- ✗ Ալիքը տեղափոխում է նյութը / կան «ձայնի մասնիկներ» → ✓ կետերը տատանվում են տեղում։
- ✗ Ձայնը վակուումում → ✓ տիեզերքում ձայն չկա։
- ✗ Մեծ լայնույթ = ավելի արագ ալիք → ✓ արագությունը նույնն է։
- ✗ Ալիքային օղակներ ճոճանակի կամ բեռի շուրջ (առանց միջավայրի) → ✓ մեխանիկական ալիքը նկարիր միջավայրում (լար, զսպանակ, ջուր)։

**Լույս և օպտիկա**
- ✗ Ճառագայթը դուրս է գալիս աչքից → ✓ ճառագայթները գնում են աղբյուրից **դեպի** աչք։
- ✗ Ուռուցիկ ոսպնյակը ցրում է → ✓ ուռուցիկը հավաքում է կիզակետում, գոգավորը ցրում է։
- ✗ Ճառագայթը «փայլում» է կողքից, մառախուղ → ✓ հարթ գիծ-մոդել։
- ✗ Սպիտակ լույսը «ներկվում է» պրիզմայում → ✓ պրիզման բաժանում է արդեն գոյություն ունեցող գույները։

**Էլեկտրականություն**
- ✗ Հոսանքը «սպառվում է» լամպում → ✓ լամպից առաջ և հետո հոսանքը նույնն է։ Փոխակերպվում է էներգիան։
- ✗ «Բախվող հոսանքներ» երկու բևեռից → ✓ մեկ ուղղություն, փակ շղթա։
- ✗ Մարտկոցը «լիցքի տարա» է → ✓ սպառումը ցույց տուր էներգիայով, ոչ թե «դատարկվող» լիցքով։
- ✗ Բաց շղթայում լամպը վառվում է → ✓ չի վառվում։

**Մագնիսականություն և ինդուկցիա**
- ✗ Դաշտի գծերը նյութական թելեր կամ խողովակներ են → ✓ բարակ, թույլ, կարճ ցուցադրվող մոդել։
- ✗ Ստատիկ մագնիսը հոսանք է առաջացնում → ✓ սլաքը շեղվում է միայն **շարժման** ժամանակ և կանգ առնելիս վերադառնում է 0-ի։
- ✗ Բևեռները լիցքեր են (+/−) → ✓ N/S։

**Ջերմային երևույթներ**
- ✗ «Սառը հոսում է», կապույտ «ցրտի ճառագայթներ» → ✓ ջերմությունը տաքից սառն է անցնում։
- ✗ Ջերմաստիճան = ներքին էներգիա = ջերմաքանակ → ✓ նույն մոտիվը (օր.՝ ջերմաչափ) երկու գլխի համար մի օգտագործիր։
- ✗ Հալման կամ եռման ժամանակ ջերմաստիճանը աճում է → ✓ փուլային անցման ժամանակ ջերմաչափը կանգնած է։ Անիմացիայում ավելացրու կարճ դադար։
- ✗ Տեսանելի «գոլորշին» ջրային գոլորշին է → ✓ տեսանելին խտացած կաթիլներն են։ Ջրի մակերեսի և «ամպիկի» միջև թող փոքր բաց տարածություն։
- ✗ Ջերմային մեքենան ունի 100% ՕԳԳ → ✓ ցույց տուր արտանետվող ջերմությունը։
- ✗ Կոնվեկցիայի սլաքներ գլխում, որտեղ կոնվեկցիա չկա → ✓ կոնվեկցիան նկարիր միայն այն գլխում, որտեղ կա համապատասխան դաս։ 8-րդում §43-ը «Կոնվեկցիա» է։

**Ատոմային և միջուկային ֆիզիկա**
- ✗ Էլեկտրոնը շարժվում է հստակ ուղեծրով (մոլորակային ատոմը արդեն 7-րդում է) → ✓ էներգիական մակարդակներ կամ ամպ։
- ✗ Ռադիոակտիվությունը կանաչ փայլ է → ✓ α/β/γ ըստ թափանցելիության (թուղթ/ալյումին/կապար)։
- ✗ Կիսատրոհումից հետո ամեն ինչ քայքայվել է → ✓ կեսը, հետո քառորդը։

**Ժամանակակից ֆիզիկա**
- ✗ Ֆոտոէֆեկտ. ավելի պայծառ լույս = ավելի արագ էլեկտրոններ → ✓ ամեն ինչ կախված է հաճախությունից (կարմիրը չի հանում, մանուշակագույնը հանում է)։
- ✗ «Ամեն ինչ հարաբերական է» → ✓ c-ն նույնն է բոլոր դիտորդների համար։
- ✗ Էլեկտրոնը մանր գնդիկ է → ✓ ինտերֆերենցիոն շերտեր։
