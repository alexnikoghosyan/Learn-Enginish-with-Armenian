# Physics path nodes — design prompt

The full rules for designing and coding learning-path nodes (the round/object buttons on `/physics/<grade>`), for any topic and for grades 9–12. Written in Armenian. It is one prompt split into three parts; read all three, in order:

1. `1-rules.md`: sections A–D (role and inputs, universal technical spec, the motif procedure, the physics-misconception checklist).
2. `2-grades.md`: sections E–I (styles for grades 9, 10, 11 and 12, the QA checklist with lessons from grade 8, output format, student test plan, evidence).
3. `3-code.md`: appendices (HTML structure, shared CSS and JS with the `__LESSONS__` / `__CUT__` placeholders, registry of motifs already used).

Final designs that already exist:
- Grade 7: https://claude.ai/artifact/4ScDErJifnKGNEfABDZsG9 (third row)
- Grade 8: https://claude.ai/artifact/CaXGDoDWJVKvRJqdet8Y6i (incline, rocket, pendulum, kettle, ice)

Chapters and lesson names always come from `PLAN.md`.
