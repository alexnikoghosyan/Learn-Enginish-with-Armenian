# ArmDuo · Կլորակների պռոմպտ · մաս 2 (E–I)

> Այս ֆայլը ArmDuo-ի կլորակների վերջնական պռոմպտի մաս 2/3-ն է։ Մասերն են. 1 — `docs/physics-nodes/1-rules.md` (A–D. դեր, տեխնիկական spec, մոտիվի ընթացակարգ, թյուրըմբռնումներ), 2 — `docs/physics-nodes/2-grades.md` (E–I. ոճեր ըստ 9–12 դասարանների, ստուգացուցակ, ելք, թեստ, ապացույցներ), 3 — `docs/physics-nodes/3-code.md` (հավելվածներ. HTML կառուցվածք, ընդհանուր CSS և JS, ռեգիստր)։ Պռոմպտն օգտագործելիս միացրու երեքը հերթականությամբ։


## E. ՈՃԵՐ ԸՍՏ ԴԱՍԱՐԱՆԻ

**Առաջընթացը 9 → 12.** հագեցվածություն ↓ · overshoot/bounce ↓ · idle ↓ · տեխնիկական ճշգրտություն ↑ · popup-ի տեղեկատվություն ↑ · dark mode-ի դեր ↑։
**Անփոփոխ են.** round/object ձևը, մուգ հաստությունը (+7px, 12-րդում +6px), երկու հարթ երանգը, Noto Sans Armenian-ը, layer-ները, JS-ը, մատչելիությունը, START-ի 800–1200 ms տիրույթը։
**Հիմնավորումը.** դեռահասները մերժում են «մանկականը», թարթող գրաֆիկան, ծանր անիմացիան և աղաղակող գույները (NN/g 2019)։ Պարգևի նկատմամբ զգայունության գագաթը մոտ 14–16 տարեկանն է, ուստի 9–10-րդում փոքր «հաղթանակի» ազդանշանները դեռ արդարացված են։ Autonomy-ն աճում է միջին դեռահասությունից սկսած։ Dark mode-ի նախասիրությունը աճում է 18–24 տարեկանների մոտ։ Ուղիղ «ըստ դասարանի» ապացույց չկա, ուստի այս բաշխումը inference է և պետք է ստուգվի (H)։

Հիշեցում. 7–8-րդ դասարանները օգտագործում են դասական Duolingo գունապնակը. կանաչ `#58CC02/#58A700/#89E219`, նարնջագույն `#FF9600/#CC7800/#FFC266`, մանուշակագույն `#CE82FF/#A568CC/#E3B5FF`, կարմիր `#FF4B4B/#EA2B2B/#FF9B9B`, դեղին `#FFC800/#E0A800/#FFE066` (banner `#8A6500`), կապույտ `#1CB0F6/#1899D6/#84D8FF`, փիրուզագույն `#00C2D1`։ Banner-ի մուգ երանգներն են `#388201`, `#A86200`, `#945DB7`, `#D13D3D`, `#137BAC`, `#008089`։

### E.9 · 9-րդ դասարան (~14–15) · «Մեծացած Duolingo»
- **Ինչու.** անցումային տարի է. պարգևի նկատմամբ զգայունությունը բարձր է, բայց «մանկականը» արդեն մերժվում է։
- **Գունապնակ** (main / dark-հաստություն / light / banner).
  - Կանաչ `#58CC02 / #58A700 / #89E219 / #388201`
  - Նարնջագույն `#FF9600 / #CC7800 / #FFC266 / #A86200`
  - Մանուշակագույն `#CE82FF / #A568CC / #E3B5FF / #945DB7`
  - Կարմիր `#FF4B4B / #EA2B2B / #FF9B9B / #D13D3D`
  - Կապույտ `#1CB0F6 / #1899D6 / #84D8FF / #137BAC`
  - Դեղին `#FFC800 / #B08400 / #FFE066 / #8A6500` (հաստությունը մգացված է 3:1-ի համար)
  - Փիրուզագույն `#00C2D1 / #0098A3 / #7FE6EE / #008089`
- **Ֆոն և տեքստ.** ֆոնը `#FFFFFF`, պիտակները `#3C3C3C`, փակը `#767676`։ Dark mode-ը պարտադիր չէ։
- **Պատկեր.** կոնկրետ առարկա, 3–4 տարր, անկյունների rx ≥4, մոտիվը մինչև Ø56։
- **Շարժում.**
  - idle. 2.4–3.6 վ, ≤4px/≤6°
  - hover. 200–250 ms, `cubic-bezier(.34,1.56,.64,1)`, overshoot ≤8%
  - tap. 320–450 ms, մեկ թեթև bounce
  - START. 1000–1200 ms, cut 750–1000
  - նշիչի pop. 300 ms (.6→1.08→1)
  - «ՍԿՍԵԼ»-ի bob. 1.6–2 վ, ±3–5px
- **Popup-ի տեքստ.** ընթացիկ՝ «Հաջորդ դասը քեզ է սպասում։», ավարտված՝ «Ավարտված է։ Կարող ես կրկնել։»
- **DO.** պայծառ հարթ գույներ, ֆիզիկայով լի շարժում, խաղային, բայց խելացի։
- **DON'T.** դեմքեր, կերպարներ, «փոքրիկ» տիպի բառեր, աստղիկներ, neon, թարթում, մեկից ավելի idle շարժում մեկ կլորակում, confetti։

### E.10 · 10-րդ դասարան (~15–16) · «Հանդարտ վստահություն»
- **Ինչու.** պարգևի պատասխանի գագաթն է և autonomy-ի աճը։ Ավելի քիչ «ձեռքից բռնել», ավելի շատ տեղեկատվություն։
- **Գունապնակ.**
  - Փիրուզագույն `#14B8A6 / #0F8F82 / #7FE0D4 / #0B6E64`
  - Կապույտ `#2B8AEF / #1F6FCC / #9CC8FA / #1A5DAD`
  - Մանուշակագույն `#8B5CF6 / #6D43D6 / #C9B5FB / #5B36B8`
  - Մարջան `#F2643D / #C94B28 / #F9AE97 / #A63D20`
  - Սաթ `#F5A524 / #B07A0C / #FBD38D / #8A5A00`
  - Կանաչ `#4CB944 / #3A9434 / #A5E09F / #2E7A29`
- **Ֆոն և տեքստ.** ֆոնը `#FFFFFF`, պիտակները `#2F3337`, փակը `#6B7280`։ Dark mode-ը միացվում է կարգավորումներից. ֆոն `#121418`, surface `#1B1E24`, տեքստ `#E6E8EC`։
- **Պատկեր.** առարկա + մեկ սխեմատիկ տարր (F սլաք, կետագծային հետագիծ), գծերը 4–5px։
- **Շարժում.**
  - idle. 3.5–4.5 վ, ≤3px/≤4°
  - hover. 180–220 ms, `cubic-bezier(.3,1.3,.6,1)`, overshoot ≤4%
  - tap. 280–350 ms
  - START. 900–1100 ms, cut 700–900
  - նշիչ. 250 ms
- **Popup-ի տեքստ.** ընթացիկ՝ «Պատրա՞ստ ես։ Այսօրվա թեման՝ {դաս}։», ավարտված՝ «Ավարտված է։ Կրկնությունը ամրացնում է։»
- **DO.** մաքուր ուրվագիծ, ֆիզիկական նշաններ, քիչ դեկոր։
- **DON'T.** կրկնվող bounce, scale >1.08, կատակներ, մուլտֆիլմային ձևեր։

### E.11 · 11-րդ դասարան (~16–17) · «Լաբորատոր գործիք»
- **Ինչու.** աշակերտները մոտենում են չափահաս նորմերին, dark mode-ը տարածված է։ Պատկերը պետք է հիշեցնի իրական սարքեր և սխեմաներ։
- **Գունապնակ.**
  - Ինդիգո `#5B6CFF / #4152D9 / #B3BBFF / #3341B8`
  - Ցիան `#06A3C4 / #04819B / #8EDCEC / #036A80`
  - Զմրուխտ `#10A36E / #0B7F55 / #86D9B9 / #086645`
  - Նարնջագույն `#F2792B / #C75A14 / #F8BC94 / #A14810`
  - Մագենտա `#D9468F / #B02E6F / #EFA3C8 / #93245B`
  - Օխրա `#D99A1E / #A87410 / #EFCB80 / #7D5600`
- **Light.** ֆոնը `#FFFFFF`, պիտակները `#2B2F36`, փակը `#6B7280`։
- **Dark (լիարժեք տարբերակ).** ֆոն `#0F1218`, surface `#171B22`, բաժանարար `#2A2F3A`, տեքստ `#E6E8EC`, երկրորդական տեքստ `#9AA3AF`։ Dark-ում ուրվագիծը սահմանում է main գույնը (≥3:1), իսկ banner-ի shadow-ը `0 4px 0 rgba(0,0,0,.4)` է։
- **Պատկեր.** սխեմատիկ (օսցիլոգրաֆի էկրան, կծիկ + գալվանոմետր, ոսպնյակ + 3 ճառագայթ), 2–3 տարր + մեկ նշան, գծերը 4px։
- **Շարժում.**
  - idle. միայն մեկ մասով, 4.5–6 վ, ≤2px/≤3°, մարմինը կանգնած է
  - hover. 160–200 ms, `cubic-bezier(.2,0,0,1)`, առանց overshoot-ի
  - tap. 220–300 ms
  - START. 850–1000 ms, cut 650–850
  - նշիչ. fade + scale .9→1, 200 ms
  - «ՍԿՍԵԼ»-ի bob. 2.4 վ, ±2px
- **Տառեր.** popup-ում ավելացրու երկրորդական տող 13px/600 `#6B7280` (օր.՝ «~8 րոպե»)։
- **Popup-ի տեքստ.** ընթացիկ՝ «{դաս} · ~{N} րոպե։ Կսկսե՞նք։», ավարտված՝ «Ավարտված։ Կարող ես կրկնել քննությունից առաջ։»
- **DO.** ճշգրիտ սլաքներ, համաչափ երկրաչափություն, հանգիստ շարժում։
- **DON'T.** overshoot, ամբողջ կլորակով idle, խաղալիքային ձևեր, «!», էմոջի։

### E.12 · 12-րդ դասարան (~17–18) · «Sleek, քննություն և համալսարան»
- **Ինչու.** աշակերտները մոտենում են 18–25 խմբին, որը NN/g-ն անվանում է «toughest audience»։ Նրանք ձգտում են չափահաս գործիքների (Notion/Linear/Spotify տիպի մակերեսներ), իսկ կենտրոնում ավարտական քննություններն են։
- **Գունապնակ.**
  - Կապույտ `#2F80ED / #1C5FC4 / #9BC2F7 / #174EA6`
  - Մանուշակագույն `#7B61FF / #5B42D6 / #C3B6FF / #4A33B5`
  - Փիրուզագույն `#0EA5A0 / #0A7C78 / #8ADBD8 / #08635F`
  - Կարմիր `#E5484D / #B8343A / #F4A3A6 / #9C2A30`
  - Սաթ `#E59A1A / #B07410 / #F3CD87 / #7A5000`
  - Կանաչ `#3FA34D / #2E7D3A / #A3D9AA / #276B32`
- **Light.** ֆոնը `#FFFFFF` / `#FAFAFB`, պիտակները `#1F2329`, երկրորդական տեքստը `#6B7280`։
- **Dark (արտահանիր և՛ light, և՛ dark).** ֆոն `#0F1115`, surface `#171A21`, բաժանարար `#262B34`, տեքստ `#E6E8EC`, փակ `#3A3F4A`։
- **Ձև.** round, հաստությունը +6px (`cy 72`), banner-ի radius-ը 12, մոտիվը ≤Ø50 (շատ «օդ»)։ Ավարտված նշիչը կարող է լինել `#2E9E4F`։
- **Պատկեր.** մինիմալ-տեխնիկական, 2–3 տարր, ֆիզիկական նշաններ (λ, E, B), ոչ թվեր, ոչ բառեր։
- **Շարժում.**
  - idle. նախնականում **անջատված** է (թույլ է մեկ մաս ≥6 վ, ≤2px)
  - hover. 150–180 ms, `cubic-bezier(.2,0,0,1)`
  - tap. 200–260 ms
  - START. 800–950 ms, cut 600–800
  - նշիչ. 150 ms crossfade
  - «ՍԿՍԵԼ»-ի bob. 3 վ, ±1.5px, կամ ստատիկ
- **Տառեր.** կլորակի պիտակը 14px/600, popup-ի տեքստը 14px/500–600։
- **Popup-ի տեքստ.** ընթացիկ՝ «{դաս} · ~{N} րոպե» (կամ «Ներառված է ավարտական քննության ծրագրում»՝ միայն թիմի հաստատմամբ), ավարտված՝ «Ավարտված։ Կրկնել»։
- **DO.** օդ, հստակ հիերարխիա, dark mode, զուսպ շարժում, ճշգրիտ ֆիզիկա։
- **DON'T.** bounce, idle բոլոր կլորակներում, մոտիվացիոն կոչեր, կերպարներ, «կոնֆետային» գույներ, մեծ check pop։

- [ ] `@keyframes` ցուցակը ստուգված և կցված է, բացակայողներ չկան, `{}`-ները հավասար են։
- [ ] `tapA/tapB` և `clickA/clickB` վերագործարկվում են։
- [ ] settle-ը 380 ms է, պտտվողների իներցիան՝ մոտ 750 ms, մկնիկը հանելիս ոչինչ կտրուկ չի վերադառնում։
- [ ] Reduced motion. ամեն ինչ կանգնած է, cut = 0։
- [ ] a11y. `<button>`, aria-*, focus-visible, X 44×44, փակ կլորակի shake։
- [ ] Busy-ն արգելափակում է մյուս կլորակները։

### F.2 8-րդ դասարանից սովորած դասեր (իրական սխալներ, որոնք չպետք է կրկնվեն)
1. **`akeyframes` / `bkeyframes`.** Tap/START-ը չէր աշխատում։ Միշտ ստուգիր B.7-ը։
2. **Եզրագծով սպիտակ շրջաններ** (գնդակ և strobe կրկնօրինակներ սպիտակ ֆոնի վրա) անպրոֆեսիոնալ տեսք ունեին։ Սպիտակ ֆոնի վրա առարկան նկարվում է գլխի գույնով, ghost-երը tinted fill են։
3. **Կլորակը artboard-ից դուրս** (`left:-30px`)։ Ստուգիր բոլոր դիրքերը։
4. **Չափազանց կարճ START** (0.3–0.6 վ). անիմացիան չէր երևում։ START-ը պետք է լինի 800–1200 ms։
5. **Թեյնիկը նման էր կողպեքի** (նեղ կամար + գլխիկ)։ Ստուգիր ուրվագիծը վիճակների նշանների հետ։
6. **Կափարիչը դուրս էր թռչում շրջանից**, և սպիտակ ֆոնի վրա անտեսանելի էր։
7. **Սառույցը պարզապես փոքրանում էր**, իսկ ջրափոսը դուրս էր գալիս շրջանից։ Հալվելը պետք է երևա որպես փուլ (ցածրանալ + ջուր հավաքվել), և ամեն ինչ պետք է մնա շրջանի ներսում։
8. **Սխալ գլուխների ցուցակ.** 8-րդում նախ օգտագործվեց 6 գլխանի ցուցակ, մինչդեռ PLAN.md-ում 5 գլուխ է։ Միշտ վերցրու PLAN.md-ից։
9. **Միևնույն ջերմաչափը երկու գլխի համար** (ջերմաստիճան ≠ ներքին էներգիա) թույլատրելի չէ։

## G. ԵԼՔԻ ՁԵՎԱՉԱՓ

1. Մեկ artboard մեկ գլխի համար՝ «Գլուխ {N} · {վերնագիր} — {մոտիվ}» վերնագրով, `is_interactive: true`։
2. Ամեն artboard-ում. պաստառ, 4 կլորակ (ավարտված, ավարտված, ընթացիկ, փակ), պիտակներ, «ՍԿՍԵԼ» պիտակ, popup-ի 3 տարբերակ, դասի էկրան։
3. 11–12-րդում. light + dark տարբերակներ (12-րդում պարտադիր)։

   `Գլուխ N · {մոտիվ} · {round|object} · idle: … · hover: … · tap: … · START … ms / cut … ms (գագաթ՝ …) · misconception: OK · keyframes: OK`

## H. ՍՏՈՒԳՈՒՄ ՀԱՅ ԱՇԱԿԵՐՏՆԵՐԻ ՀԵՏ

Գրականությունը չի կարող ասել, թե ինչ են նախընտրում հենց ArmDuo-ի աշակերտները։ Ամեն դասարանի ոճը հաստատելուց առաջ.
- **5 վայրկյանի ճանաչում.** կլորակը 72px-ով, իրական հեռախոսում, 5 վայրկյան, հարց՝ «Ֆիզիկայի ո՞ր թեմայի մասին է»։ Ամեն դասարանից ≥12–30 աշակերտ։ ≥70% ճիշտ → OK, <50% → փոխիր մոտիվը։
- **Զույգային նախընտրություն.** նույն գլուխը երկու ոճով (կամ երկու մոտիվով), պատահական հերթականությամբ, ձախ/աջ հավասարակշռված, հարց՝ «Ո՞րն է ավելի լավ սազում ֆիզիկայի հավելվածին»։ Ամեն դասարանից ≥30 աշակերտ։ ≥21/30 (≈70%, binomial p < .05) → ընդունիր։
- **«Մանկակա՞ն է» 1–7 սանդղակով.** միջինը ≤3.0 → OK, ≥4.0 → նվազեցրու հագեցվածությունը և overshoot-ը։
- **Նյարդայնացում.** START-ը 10 անգամ անընդմեջ, հետո 1–5 սանդղակ։ >3 → կրճատիր 100–150 ms-ով, բայց ոչ 800-ից ցածր։
- Թեստն արա հին/միջին Android հեռախոսով, Երևանում և մարզում։ Անչափահասների համար ստացիր ծնողների կամ դպրոցի համաձայնությունը։
- Սցենար (հայերեն). «Բարև։ Մենք ստեղծում ենք ArmDuo հավելվածի ֆիզիկայի բաժինը և ուզում ենք իմանալ քո կարծիքը։ Ճիշտ կամ սխալ պատասխան չկա։ Էկրանին մի պահ նկար կհայտնվի։ Երբ անհետանա, ասա, թե ֆիզիկայի որ թեմայի մասին է այն։ Հետո ցույց կտանք երկու նկար. ընտրիր այն, որն ավելի լավ է սազում ֆիզիկայի հավելվածին։ Վերջում գնահատիր ամեն նկարը 1-ից 7. որքանո՞վ է այն քեզ թվում փոքր երեխաների համար։ 1՝ բոլորովին ոչ, 7՝ միանգամայն մանկական։ Շնորհակալություն։»
